# 모아검색 v0.4.2 — 모델명과 용도 표시 개선

앱 화면과 안내에서 실제 사용하는 모델명과 양자화 방식을 명확히 표시합니다.

| 용도 | 모델명 | 모델 파일 |
| --- | --- | --- |
| 자연어 의미 검색·임베딩 | Google EmbeddingGemma 2 Q8_0 | `embeddinggemma-2-Q8_0.gguf` |
| 검색한 문서에 근거한 답변 | Google Gemma 4 E2B IT QAT Q4_0 | `gemma-4-E2B_q4_0-it.gguf` |
| 이미지·스캔 PDF 문자 인식 | PP-OCRv5 한국어·영어 OCR | `ch_PP-OCRv5_det_mobile.onnx`, `korean_PP-OCRv5_rec_mobile.onnx` |

- 상태 카드에 검색·답변 모델명과 각각의 준비 상태 표시
- 설정 입력란, 모델 받기 버튼, 다운로드 진행·완료 안내와 오류에 모델명 명시
- 긴 모델명이 잘리지 않도록 상태 카드 줄바꿈과 설정 버튼 배치 조정
- README와 구조 문서에 용도·양자화·파일명을 정리하고 PP-OCRv5를 두 Google GGUF 모델과 구분

표시와 안내를 개선한 버전이며, 고정 모델 파일·다운로드 주소·SHA-256과 검색 데이터 형식은 동일합니다. 앱과 설치 프로그램은 코드 서명하지 않았습니다.

화면·IPC 테스트 11개와 Windows 빌드가 통과했습니다. 실제 설치를 v0.4.2로 업데이트한 뒤 상태 카드, 설정 입력란과 모델 받기 버튼에서 모델명·양자화·준비 상태가 잘리지 않고 표시되는 것을 확인했습니다.
