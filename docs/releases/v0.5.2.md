# 모아검색 v0.5.2 — 검색 일치 파일 전체 탐색

검색어를 입력했을 때도 일치하는 파일을 30개로 자르지 않고, 전체 개수와 함께 끝까지 탐색할 수 있습니다.

- 파일명·경로, 본문 키워드, 소스코드 종류 검색의 중간 후보 상한을 제거합니다. 같은 파일의 여러 본문 구간은 파일 하나로 합칩니다.
- 의미 검색은 기존 관련성 기준에 맞는 모든 파일을 포함하며, 페이지 크기로 후보를 잘라내지 않습니다.
- 결과를 페이지로 나누고 보이는 행 주변만 그립니다. 다음 페이지는 이미 계산한 검색 결과를 재사용하여 AI 분석을 반복하지 않습니다.
- 결과가 크면 임시 파일을 사용해 메모리 캐시 기준 때문에 일치 파일이 사라지지 않게 합니다. 임시 데이터는 이 PC에서만 관리합니다.
- 페이지 추가 시 스크롤·선택·포커스를 유지합니다. 검색어·폴더·종류·검색 방식이 달라지거나 검색 결과가 교체되면 이전 페이지 응답을 무시합니다.
- 파일 정보나 본문이 변경된 경우 목록을 새로 읽고, 벡터만 백그라운드에서 갱신될 때는 현재 검색의 순서를 유지합니다.

빈 검색어 전체 목록, 입력 즉시 키워드 검색, 한글 조합, 탐색기 폴더 범위 검색을 유지합니다. Windows x64 설치 파일과 포터블 ZIP을 제공합니다.

검색 모델은 **Google EmbeddingGemma 2 Q8_0**, 선택형 답변 모델은 **Google Gemma 4 E2B IT QAT Q4_0**입니다. 기존 색인·설정·모델을 유지합니다.

Rust **91개**, 화면·브리지 **44개** 테스트가 통과했습니다. 실제 색인 **14,088개**에서 3,126개 일치 결과와 14,088개 일치 결과를 각각 끝까지 조회해 누락·중복 0개를 확인했습니다. 폴더 범위 217개와 기존 자연어 검색 6개 사례도 검증했습니다. 처음 전체 일치를 계산한 뒤 다음 페이지 평균은 약 **5~7ms**였으며, 광범위한 한 글자 질의의 최초 계산은 약 **3초**였습니다. 앱 시작·IPC·렌더를 제외한 호출 시간과 조건은 [성능 검증 기록](https://github.com/hebory/moasearch/blob/v0.5.2/docs/performance.md#rust-v052)에서 확인할 수 있습니다.

실제 PC에 설치해 200→400개 이어 읽기, 페이지 경계의 방향키 이동, Home·End, 마지막 페이지 위아래 스크롤과 검색어 지우기를 직접 확인했습니다. 검증 중 발견한 키보드 스크롤 오류도 수정 후 재설치했습니다. 기존 색인·설정을 보존하고 최종 설치 payload 및 ZIP의 크기·SHA-256 검증을 마쳤습니다.

설치 프로그램과 앱 실행 파일에는 코드 서명이 적용되지 않았습니다. 첨부한 `SHA256SUMS.txt`와 manifest로 배포 파일의 무결성을 확인할 수 있습니다.
