# 모아검색 v0.4.1 — 탐색기 메뉴와 화면 검색 수정

실제 설치 앱과 탐색기 화면을 조작하며 발견한 문제를 수정했습니다.

### 수정 내용

- 폴더 빈 공간에서 **모아검색으로 여기서 검색**이 보이지 않던 문제 수정
- 업데이트 시 이전 버전의 잘못된 메뉴 선택 조건 제거, 설치·제거 후 탐색기 등록 갱신
- 검색어 변경 직후 이전 검색어로 질문하던 문제 수정
- 검색 대기·진행 중 질문 버튼 비활성화, 최신 검색 완료 후 활성화, 입력 변경 시 이전 답변 숨김

### 실제 설치·화면 검증

- AI 모델 경로 설정·저장, 폴더 추가, 색인 시작, 파일 8개·본문 구간 9개·임베딩 9개 확인
- 이미지 OCR·스캔 PDF 자연어 검색과 본문 미리보기, HWP·HWPX 키워드 검색 확인
- 실제 탐색기의 폴더·빈 공간 우클릭 메뉴 실행과 같은 폴더 창 재사용 확인
- 선택 폴더와 하위 폴더 결과 2개, 범위 해제 시 형제 폴더를 포함한 결과 3개 확인
- 실제 설치를 v0.4.1로 업데이트한 뒤 잘못된 메뉴 값 정리와 기존 색인·모델 설정 보존 확인
- 종료 확인 창의 취소·종료 동작, 화면·IPC 테스트 11개, 네이티브 실행·폴더 범위 회귀 검증 통과
- 설치 파일 761개의 SHA-256 검증, 앱의 TCP 리스너 0개 확인

### 설치

기존 모아검색을 종료하고 `moasearch-0.4.1-win-x64-setup.exe`로 업데이트하세요. 탐색기 메뉴를 사용하려면 설치 옵션 **탐색기에서 현재 폴더 검색**을 선택합니다. 포터블 ZIP도 제공합니다.

모델은 패키지에 포함하지 않습니다. 모델과 필요한 WebView2 Runtime을 처음 받을 때는 인터넷이 필요하며, 준비 후 검색·OCR·AI 추론은 로컬에서 실행됩니다. 앱과 설치 프로그램은 코드 서명하지 않았습니다.

검증은 WebView2가 설치된 Windows PC에서 테스트 문서와 로컬 모델로 수행했습니다. 깨끗한 VM, WebView2 미설치 분기와 답변 모델의 생성 품질 평가는 포함하지 않았습니다.
