# 모아검색 v0.4.0 — 데스크톱 명령 통합

화면과 Rust 검색 기능의 연결을 앱 내부 명령 구조로 통합했습니다.

### 변경 내용

- localhost HTTP 서버, TCP 리스너, 포트 설정 제거
- 검색 화면을 WebView2의 내장 리소스로 표시하고 typed IPC 브리지로 Rust 서비스 호출
- 화면과 CLI의 색인·검색·답변을 공통 Rust 서비스로 통합
- 사용자와 데이터 폴더별 Windows 앱 인스턴스 관리
- Windows 명명된 파이프는 탐색기의 폴더 열기, 인스턴스 상태, 앱 종료 요청에만 사용
- 화면 검색·색인·OCR·로컬 모델 작업을 worker에서 실행하고 마지막 창을 닫을 때 진행 작업 정리
- `instance`, `quit` 명령으로 실행 상태 확인과 앱 종료 지원

### 설치와 사용

이전 버전의 모아검색을 종료한 뒤 업데이트하세요. Windows 설치 프로그램이나 포터블 ZIP에서 `moasearch.exe`를 실행합니다. WebView2 Runtime이 필요한 PC에서는 설치 프로그램이 Microsoft Runtime을 준비합니다. 모델은 패키지에 포함하지 않으며, 처음 사용할 때 내려받기 위해 인터넷 연결이 필요합니다. 모델 설치 후 검색·OCR·AI 추론은 로컬에서 실행됩니다.

설치 프로그램에서 탐색기 메뉴를 선택하면 폴더나 빈 공간을 우클릭해 **모아검색으로 여기서 검색**을 열 수 있습니다. 검색 결과는 선택한 폴더와 하위 폴더에 한정됩니다.

앱과 설치 프로그램은 코드 서명하지 않았습니다.

### 검증 결과

- Rust 단위·통합 테스트 42개, 추가 연결 과부하 회귀 테스트 1개, 화면 IPC 테스트 9개 통과
- 실제 Windows 창의 내부 명령 통신, 동시 실행 시 기존 앱 재사용, 데이터 위치별 격리 및 정상 종료 확인
- 배포 실행 파일과 설치된 앱 모두 TCP 리스너 0개 확인
- 설치 앱에서 HWP·HWPX·이미지·PDF 등 8개 파일 색인과 9개 임베딩 생성, 이미지 OCR·스캔 PDF·혼합 PDF 자연어 검색 확인
- 탐색기 메뉴 설치·선택 해제·복원·제거, 선택 폴더 및 하위 폴더 검색, 제거 후 모델·색인 데이터 보존 확인
- 공개 파일 체크섬과 ZIP 내부 762개 파일의 SHA-256 검증

기존 설치를 보존하는 별도 AppId로 동일한 배포 파일과 설치 로직을 검증했습니다. WebView2가 설치된 Windows PC에서 확인했으며 깨끗한 VM과 화면 직접 조작 검증은 포함하지 않았습니다.
