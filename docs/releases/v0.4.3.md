# 모아검색 v0.4.3 — 무관한 검색 결과 노출 개선

`소스코드` 검색에 관계없는 HWP/HWPX가 표시될 수 있었던 검색 정책을 수정했습니다. 이전에는 의미 유사도가 낮아도 상위 후보를 결과로 추가했습니다.

- `소스코드`·`소스 코드`·`source code`는 소스 파일 확장자와 해당 표현의 문자 일치를 사용해 검색
- 실제 표현이 없는 무관한 문서를 의미 유사도만으로 소스코드 결과에 추가하지 않도록 수정
- 일반 자연어 검색의 낮은 관련도 후보 제외, 답변 근거에도 같은 기준 적용
- 여러 단어의 자연어 질의에서 한글 한 글자만 우연히 맞는 문서의 노출 완화
- `의미 일치`를 `의미 유사`로 바꾸고 파일명·경로·본문 키워드·파일 종류 근거를 함께 표시
- 새 검색어를 입력하면 이전 결과와 미리보기를 바로 비워 결과 혼동 방지

HWP 등도 실제 검색 표현이 파일명·경로·본문에 있으면 결과로 남습니다. 관련도 필터는 현재 고정된 **EmbeddingGemma 2 Q8_0**에 맞춘 보수적 기준이며, 모든 문서의 관련성을 완벽히 판정하거나 누락을 없애는 것은 아닙니다. 기준과 평가 범위는 저장소의 `docs/search-relevance.md`에 기록했습니다.

### 검증

- Rust 단위·통합 테스트 49개, 화면·IPC 테스트 12개 통과
- 별칭 보완 후 검색 회귀 테스트 16개 재검증 통과
- 고정 EmbeddingGemma 2 Q8_0와 가상 본문 12개의 관련성 평가 8개 통과
- 소스 파일·관련 문서는 유지하고 무관 HWP/HWPX 제외, 자료에 없는 두 주제는 결과 0개 확인
- 실제 설치 앱의 `소스코드` 검색은 기존 8개(의미 후보 HWP/HWPX 2개 포함)에서 수정 후 0개로 변경. `소스 코드`도 0개이며 기존 색인·모델 설정 보존 확인
- 실제 화면에서 검색 종류 안내·빈 결과·이전 카드 제거 확인, 최종 실행 파일의 탐색기·폴더 범위 회귀 검증 통과

앱을 종료한 뒤 설치 파일로 업데이트하세요. 모델을 다시 다운로드하거나 전체를 다시 색인할 필요는 없습니다. 앱과 설치 프로그램은 코드 서명하지 않았습니다.
