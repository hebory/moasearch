# 모아검색 v0.5.0 — 파일명 우선 검색과 CUDA 가속

Windows 설치형 앱 안에서 파일명 목록을 먼저 검색에 공개하고, 본문·OCR 추출과 EmbeddingGemma 2 Q8_0 임베딩을 백그라운드로 처리합니다. 검색과 색인은 같은 앱에서 동작하며 별도 AI 서버를 설치하지 않습니다.

- 파일명을 등록한 뒤 본문을 추출하고, 추출된 본문은 임베딩을 기다리지 않고 키워드 검색에 반영합니다.
- 자연어 검색은 이름·본문 일치 결과를 먼저 보여준 뒤 의미 검색 결과로 갱신합니다. 새 검색으로 바뀌면 이전 응답은 무시합니다.
- 배경 임베딩 중에는 바뀌지 않은 이름·본문 조회를 재사용합니다. 본문이나 파일 정보가 바뀌면 캐시를 무효화하여 검색 결과를 갱신합니다.
- 검색 질의가 기다리면 다음 색인 조각보다 먼저 실행합니다. 이름·본문 검색과 상태 조회는 모델 작업 대기열과 분리합니다.
- CUDA GPU를 자동 사용하고, 장치 탐지·추론에 실패하면 CPU로 전환합니다. 설정에서 CPU 전용 실행도 선택할 수 있습니다. OCR은 CPU에서 실행합니다.
- 자연어 파일 검색에는 **EmbeddingGemma 2 Q8_0**만 사용합니다. **Gemma 4 E2B IT QAT Q4_0** 답변은 기본 꺼짐이며 설정에서 켤 수 있습니다. 기본 준비 스크립트도 검색·OCR 모델만 받습니다.
- 변경 파일의 이전 본문·벡터를 무효화하고, 버전이 같은 결과만 저장합니다. 취소 후에도 준비된 이름·본문과 완료된 임베딩은 유지하여 다음 색인에서 이어갑니다.
- 같은 파일·본문 조각을 재사용하며, 한 임베딩 묶음 안의 중복 조각도 한 번만 계산합니다.
- Windows 폴더 변경 알림으로 자동 갱신하고 주기 점검으로 알림 누락을 보완합니다. 자동 색인 간격 0은 자동 갱신 전체를 끕니다.
- 검색창을 상단에 고정하고 파일명·경로·크기·수정일·일치 근거를 촘촘한 목록으로 표시합니다. 큰 시작 배너와 결과 카드를 없애고 선택한 파일의 본문은 미리보기에서 확인합니다.
- `Ctrl+F`·`F3`, 화살표 선택, `Enter`·더블클릭 파일 열기, `Ctrl+Enter` 위치 표시를 지원합니다. 별도의 앱 종료 버튼·확인창을 없애고 Windows 창 닫기(X)·`Alt+F4`로 닫습니다.

기존 `_site`, `temp`, `vendor`의 파일명 전용 정책과 탐색기 **모아검색으로 여기서 검색**을 유지합니다. 모델과 사용자 색인 데이터는 업데이트로 삭제하지 않습니다.

실제 파일 14,074개의 빈 DB 최초 색인에서 파일명 전체 등록은 **3.36초**, 본문·OCR·임베딩 완료는 **7분 23초**, 오류는 **0건**이었습니다. 본문 준비 후 GPU 색인 중 반복 자연어 질의는 중앙값 **68ms**, P95 **144ms**였습니다. 두 Rust 검색 호출의 합계이며 반복 질의 캐시를 포함하고 화면 입력·렌더 시간은 제외합니다. [실제 폴더 성능 측정과 검증 방법](https://github.com/hebory/moasearch/blob/v0.5.0/docs/performance.md#rust-v050)에서 최초 색인과 반복 질의를 구분해 확인할 수 있습니다.

Windows x64 설치 파일 `moasearch-0.5.0-win-x64-setup.exe`와 포터블 ZIP을 제공합니다. CUDA·ONNX Runtime·MSVC 런타임과 라이선스 고지를 포함하며, GGUF·OCR 모델은 별도로 준비합니다. GPU 가속에는 호환되는 NVIDIA GPU·드라이버가 필요하고, CPU 실행에는 AVX2가 필요합니다.

Rust 테스트 83개와 화면·브리지 테스트 24개를 통과했습니다. 실제 설치 후 기존 색인·설정 보존, 실제 폴더 검색과 미리보기, 키보드 파일 위치 열기, 탐색기 우클릭 범위 검색, 확인창 없는 표준 닫기를 검증했습니다. ZIP 766개·설치 payload 765개 파일의 크기와 SHA-256도 확인했습니다.
