Windows 설치형 데스크톱 앱으로 실행하고, 탐색기에서 선택한 폴더를 바로 검색할 수 있습니다.

### 추가된 기능

- 폴더와 폴더 빈 공간 우클릭에 **모아검색으로 여기서 검색** 메뉴 등록
- 외부 브라우저 없이 모아검색 전용 Windows 창에서 실행
- 선택한 폴더·하위 폴더 안에서 파일명, 본문, 자연어 검색 및 AI 답변 근거 검색
- 검색 범위 표시·해제와 미색인 폴더의 색인 시작
- 실행 중인 앱과 같은 폴더 창 재사용, 다른 폴더는 독립된 창에서 검색
- 마지막 창 닫기 또는 **앱 종료**로 색인을 정리하고 앱 종료
- 한글·공백·특수문자 경로 지원, 잘못된 경로는 전체 검색으로 전환하지 않고 오류 표시

### 설치와 사용

`moasearch-0.3.0-win-x64-setup.exe`를 실행하고 **탐색기에서 현재 폴더 검색** 옵션을 켜세요. 시작 메뉴·바탕화면에서 전용 앱을 열거나 폴더와 빈 공간을 우클릭해 사용할 수 있습니다. Windows 11에서는 **추가 옵션 표시**에 나타날 수 있습니다. 이전 모아검색 프로세스가 실행 중이면 종료하고 업데이트하세요.

처음 검색하는 위치에서는 **색인 시작**을 누릅니다. 등록된 다른 위치도 함께 갱신하지만 검색·답변 결과는 선택한 폴더 안으로 제한됩니다. 범위는 앱 창마다 독립적입니다. 같은 데이터 위치와 기본 포트의 앱을 재사용하며, 별도 포트로 실행한 앱은 CLI `open-folder --port`로 연결할 수 있습니다.

설치 옵션을 해제해 다시 설치하거나 앱을 제거하면 우클릭 메뉴도 제거됩니다. 색인·모델 등 앱 데이터는 유지합니다. 포터블 ZIP은 탐색기 메뉴를 등록하지 않습니다.

### 배포 파일

- `moasearch-0.3.0-win-x64-setup.exe`: 일반 설치·모아런처용
- `moasearch-0.3.0-win-x64.zip`: 포터블 실행
- `moalauncher.json`: 모아런처 설정 → 카탈로그 가져오기
- `icon.png`, `cover.png`: 모아런처용 이미지
- `SHA256SUMS.txt`, `moasearch-0.3.0-win-x64-manifest.json`: 체크섬·배포 명세

Windows 10/11 x64, AVX2 지원 CPU가 필요합니다. 앱은 Rust와 내장 llama.cpp로 Google 모델을 로컬 실행하며 Python·Ollama는 필요하지 않습니다. 모델은 설치 파일에 포함하지 않고 앱에서 별도로 다운로드합니다. 실행 파일과 설치 파일은 코드 서명되지 않았습니다.

화면을 표시하는 Microsoft WebView2 Runtime이 없는 PC에서는 설치 중 공식 Runtime을 내려받으므로 인터넷이 필요합니다. 포터블 ZIP에서는 포함된 MicrosoftEdgeWebview2Setup.exe를 먼저 실행하세요.
