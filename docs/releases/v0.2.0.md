모아검색의 첫 Windows 설치 패키지입니다. Rust 앱에서 Google 모델을 직접 실행하며 Python·Ollama·별도 AI 서버가 필요하지 않습니다.

### 다운로드

- **moasearch-0.2.0-win-x64-setup.exe**: 일반 설치 및 모아런처 설치용. 현재 사용자에게 설치하며 관리자 권한을 요구하지 않습니다.
- **moasearch-0.2.0-win-x64.zip**: 압축을 풀고 `moasearch.exe`를 실행하는 포터블 패키지.
- **moalauncher.json**: 모아런처 설정의 카탈로그 가져오기에서 선택하는 등록 파일.
- **icon.png / cover.png**: 모아런처용 아이콘과 커버.
- **SHA256SUMS.txt / moasearch-0.2.0-win-x64-manifest.json**: 배포 파일 체크섬과 구성 명세.

Windows 10/11 x64용 CPU 빌드입니다. 로컬 AI 추론은 AVX2 지원 CPU가 필요합니다. ONNX Runtime과 Microsoft VC 런타임 DLL을 함께 포함합니다. 이번 실행 파일과 설치 파일은 코드 서명되지 않았습니다.

### 처음 사용하기

1. 설치 파일을 실행하거나 모아런처에서 `moalauncher.json`을 가져온 뒤 모아검색을 설치합니다.
2. 앱을 실행하고 **AI 설정**에서 임베딩·답변·OCR 모델을 준비합니다.
3. 검색할 폴더를 추가하고 색인을 시작합니다.

Google **EmbeddingGemma 2**로 의미를 검색하고 **Gemma 4 E2B**로 문서 근거 답변을 생성합니다. Qwen 모델은 사용하지 않습니다. 모델 합계 약 3.68 GB는 설치 파일에 포함하지 않으며, 앱에서 고정 버전·SHA-256을 확인해 내려받습니다. 모델 설치 후 문서 처리와 추론은 PC 안에서 동작합니다.

### 포함한 기능

- 파일명·본문 키워드 검색과 한국어 자연어 검색
- 이미지 및 스캔 PDF의 한국어·영어 OCR
- HWP5/HWPX, PDF, Office 문서와 텍스트 파일 읽기
- 변경된 파일만 처리하는 증분 색인, 취소, 검색 캐시
- 이전 SQLite 색인 보존 및 Google 모델로 재색인

기본 데이터는 `%LOCALAPPDATA%\MoaSearch`에 보관합니다. 프로그램 설치 위치와 분리되며 설치 제거 시 색인·모델을 삭제하지 않습니다. 이전 Python 버전 사용자는 해당 서버를 종료하고 같은 데이터 위치로 전환한 뒤 다시 색인하세요.

한글·공백 경로의 무인 설치, 설치본의 Google 자연어 검색·OCR·HWP/HWPX 색인, 포함된 런타임 로드, 설치 제거 후 데이터 보존을 검증했습니다. 설치 파일은 약 11.5 MB, 포터블 ZIP은 약 15.8 MB입니다.

검증 범위와 측정 조건은 저장소의 [성능 기록](https://github.com/hebory/moasearch/blob/v0.2.0/docs/performance.md), 설치 패키지 검증 결과와 재현 방법은 [릴리스 문서](https://github.com/hebory/moasearch/blob/v0.2.0/docs/releasing.md)에 있습니다.
