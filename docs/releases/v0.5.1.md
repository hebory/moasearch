# 모아검색 v0.5.1 — 전체 파일 목록과 즉시 검색

검색어를 입력하지 않아도 색인된 파일을 이름순으로 보여줍니다. 탐색기에서 연 폴더 범위와 파일 종류 필터는 전체 목록에도 적용됩니다.

- 파일 목록은 본문·OCR·임베딩과 분리된 메타데이터 조회를 사용하며 AI 모델을 로드하지 않습니다.
- 목록을 작은 페이지로 이어 불러오고 보이는 행 주변만 화면에 그려, 파일이 많아도 한꺼번에 수만 개의 행을 만들지 않습니다.
- 검색어를 입력하면 파일명·본문 일치 검색을 바로 시작합니다. 의미 검색은 입력이 잠깐 멈춘 뒤 보완하고, 빠르게 이어 입력하면 최신 입력을 우선합니다.
- 한글 조합 중에는 불완전한 글자로 반복 요청하지 않고 조합이 끝나면 검색합니다. 조합을 확정하는 Enter는 파일을 열지 않습니다.
- 검색어를 지우면 전체 파일 목록으로 돌아갑니다. 입력·범위·필터가 바뀌기 전의 응답은 새 목록을 덮지 않습니다.
- 파일 정보가 변경된 동안의 페이지를 섞지 않고 새 목록으로 갱신합니다. 본문·벡터만 갱신할 때는 전체 목록을 다시 읽지 않습니다.

Windows x64 설치 파일과 포터블 ZIP을 제공합니다. 기존 색인·설정·모델을 유지하며, 탐색기 **모아검색으로 여기서 검색**과 확인창 없는 표준 닫기를 지원합니다. 검색 모델은 **Google EmbeddingGemma 2 Q8_0**, 선택형 답변 모델은 **Google Gemma 4 E2B IT QAT Q4_0**입니다.

Rust 테스트 **84개**, 화면·브리지 테스트 **32개**를 통과했습니다. 실제 색인 14,082개를 71페이지로 끝까지 읽어 누락·중복 0개를 확인했고, 첫 200개 조회는 약 **3.9ms**였습니다. 기존 파일명 접두어 7개의 즉시 조회는 **4.47~24.69ms**였습니다. 앱 시작·IPC·화면 렌더를 제외한 Rust 호출 시간이며, [측정 조건과 재현 방법](https://github.com/hebory/moasearch/blob/v0.5.1/docs/performance.md#rust-v051)을 함께 확인할 수 있습니다.

실제 PC에서 설치 후 전체 목록·페이지 추가·스크롤과 선택 유지·Enter 없는 연속 검색·검색어 지우기·폴더 범위 목록을 직접 조작했습니다. 검증 중 실제 새 파일 6개가 자동 반영된 최신 14,088개 색인과 설정도 유지했습니다. 최종 설치 파일과 ZIP의 payload 크기·SHA-256 검증을 마쳤습니다.
